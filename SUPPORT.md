# Get Support for cli-flames-machine

Thank you for using cli-flames-machine! This document explains the best places to get help, report issues, and find information about supported versions.

## 1. Supported Versions and Maintenance 🛠️

We only provide active support, bug fixes, and security patches for the versions listed below. If you are using an older version, please upgrade to the latest supported major release before submitting a bug report.

| Branch/Version | Status | Notes |
| :--- | :--- | :--- |
| **Latest Major Release (v1.0.0)** | **Active Support** | Receives all bug fixes, security patches, and new features. |
<!-- | **Previous Major Release (vY.x.x)** | **Maintenance Mode** | Receives critical bug fixes and security patches only. |
| **All Older Versions** | **Unsupported** | No further bug fixes or security patches will be issued. | -->

> **Requirement:** All bug reports must be reproducible on the **Latest Major Release** to be considered for a fix.


## 2. General Questions and Implementation Help 💬

If you have a general **"How-to" question**, need help with **implementation**, or want to start a **casual discussion**, please use our community forums. This helps keep our Issues tracker focused on bugs and features.

**Recommended:** Use the [**GitHub Discussions Tab**](https://github.com/VeldasRDurai/cli-flames-machine/discussions/new/general) for quick Q&A.

## 3. Reporting Issues and Bugs 🐛

If you have confirmed that you have found a bug in a **Supported Version**, please use the GitHub Issues tracker.

[**Open a New Issue**](https://github.com/VeldasRDurai/cli-flames-machine/issues) and use the Bug Report Template

## 5. Security Vulnerability Reporting 🛡️

**DO NOT** use public Issues or Discussions for security concerns.

For all security vulnerabilities, please refer to our dedicated policy: [**SECURITY.md**](https://github.com/VeldasRDurai/cli-flames-machine/security/policy) for instructions on private, responsible disclosure.
