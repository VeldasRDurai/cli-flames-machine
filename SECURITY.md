# Security Policy and Disclosure for cli-flames-machine

## 🛡️ Reporting a Vulnerability

We take the security of cli-flames-machine and our users seriously. We appreciate the efforts of security researchers and the community in disclosing vulnerabilities responsibly.

**DO NOT** open a public GitHub Issue for security issues.

### Private Reporting Method

Please report all vulnerabilities privately and directly to the maintainers via email:

* **Email:** [security@cli-flames-machine.com](mailto:security@cli-flames-machine.com)
* **Subject:** `VULNERABILITY REPORT: cli-flames-machine`

### Information to Include

To help us quickly assess and remediate the issue, please include the following details in your report:

1.  **Vulnerability Description:** A brief, clear description of the vulnerability.
2.  **Steps to Reproduce:** Exact steps to demonstrate the vulnerability.
3.  **Impact:** How could an attacker exploit this vulnerability?
4.  **Affected Versions:** Which version(s) of the package are affected?
5.  **Proof of Concept (PoC):** Any accompanying files, code, or video demonstrating the exploit (preferred).

## 🕒 Policy and Timeline

We commit to the following standard response times:

| Action | Timeframe |
| :--- | :--- |
| **Response Acknowledgment** | Within 48 hours of receipt. |
| **Fix ETA Provided** | Within 5 days of acknowledgment. |
| **Public Disclosure** | Once the fix is released, a public advisory will be issued on our GitHub Security Advisories page. |

We request that researchers keep the vulnerability confidential until we have released a patch and publicly announced the fix.
